# Advanced string functions

Strings come with many built-in methods. Two that you will use all the time when reading data from files are `split` and `strip`. Read their documentation in the Python docs and try a few examples yourself:

* [`str.split`](https://docs.python.org/3/library/stdtypes.html#str.split): cut a string into a list of parts, for example at every comma.
* [`str.strip`](https://docs.python.org/3/library/stdtypes.html#str.strip): remove whitespace, such as the newline at the end of a line, from both ends of a string.
